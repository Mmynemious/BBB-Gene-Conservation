My reading

Now I am reading this paper, which is called the comparative transcriptomics analysis pipeline for the meta-analysis of phylogenetically divergent datasets, which is an amazing project. It encounters all the problems we had, specifically with orthologues and how orthologues differ from species to species, and also the RNA sequencing datasets have been taken into consideration in terms of data divergence.

This pipeline aims at retrieving gene expression data from any RNA sequencing dataset using de novo assembly, standardized gene expression tools, and the implementation of OrthoMCL, in order to allow for faster and more statistically, or bioinformatically, clean datasets. It is a much clearer approach. They have demonstrated this project on two mouse brain transcriptomes.

The background for this project was that transcriptional regulation is an important player for certain diseases, and also for certain gene expression between different species. The issue with all of that is that transcriptomic divergences between groups are time consuming for researchers to understand, and even more so how to categorize, for instance, different orthologues. So that is the issue we had: we were not sure how to categorize orthologues and how to use their gene expression levels accordingly.

They are solving this issue by introducing CoRMAP. It processes raw datasets in the same way for each species. OrthoMCL creates orthologous groups and allows for gene expression analysis in relation to the different orthologous groups.

That is where I am currently at. I will continue reading.

The workflow figure. I have come across their figure, which explains CoRMAP in a better way. The first thing that happens in this pipeline is to:

  1. Download the RNA sequencing raw data from public repositories.
  2. Clean the data.
  3. Do de novo assembly.
  4. Quantify all gene expression values. I assume it is something that we can input.
  5. Predict the protein sequences.
  6. Find orthologous relationships between species and/or taxonomic groups with the OrthoMCL pipeline, which is not elaborated in this figure.
  7. Annotate the mammalian sequences as representative, using BLASTP, BLASTX and Trinotate.
  8. Report a metadata table.
  9. Allow for the downstream analysis with the OGG analysis, which I think they have also published, so this tool also belongs to them.

Where I am. I have only read the abstract, background and implementation, and I have been skimming through the results section.

Using it on my own project. This is a very clear mechanism to actually use. They are talking about any RNA sequencing dataset, so that means in theory I should be able to test it on my own project. This is something you need to run locally, but I do not have the hardware requirement: they talk about 100 gigabytes of free space for the OrthoMCL step, which I do not have. Since we have the code, I have been wondering whether I could create some kind of software for easier use.

I do see that it calls other tools, but I was assuming that it would be possible to use it on any type of RNA sequencing dataset, because they explicitly say it is developed for the meta-analysis of phylogenetically divergent datasets. Human, macaque and mouse are somewhat divergent, specifically human and mouse, with I think 90 million years of evolution apart.

What I take from it

An amazing project, and a much clearer approach. It encounters all the problems we had, specifically with orthologues and how to use their gene expression levels.

Checks against the paper

  • Is this the same orthologue categorisation problem? Yes. CoRMAP does not choose between one-to-one and one-to-many: OrthoMCL clusters orthologues and in-paralogues into orthologous gene groups, and expression is compared per group.
  • Is quantification something that can be input? It is done by the pipeline: reads are mapped back to the assembly and quantified with RSEM inside Trinity, then normalised to TPM. The input is raw RNA sequencing data, either public or one’s own.
  • Is the OGG analysis their own published tool? The OGG analysis is part of CoRMAP itself, written as their own R scripts. OrthoMCL, Trinity and Trinotate are existing tools by others.
  • Are human and mouse about 90 million years apart? Yes, roughly. Common estimates place the human and mouse split at about 75 to 90 million years ago.
  • Could CoRMAP’s code be built into easier software? Yes. The code is released under the GPL-3.0 licence, which allows modifying and sharing it, provided the new software is also GPL-3.0, keeps the authors’ credit, and states what was changed.
