Register — all 15 numbered steps

Run is the order the scripts actually execute in, which is not the order the step names imply: step4b writes the file step3b reads, so 4b runs before 3b.

Step Run What it does · what's wrong Verdict
step1 1 Build the master BBB gene list. Three of the four Daneman tables are the wrong tables — S3 is the pericyte-specific list (Pdgfrb, Kcnj8, Vtn, Zic1), S4 and S5 are developmentally up- and down-regulated CNS vascular genes. S6, the real BBB-enriched table, was never opened. A further 92 genes were lost silently: 18 to toupper() mangling the lowercase orf convention, 74 to HomoloGene's 2014 gene names. Wrong sources
step2 2 Process the Wälchli Seurat object. Method correct — grouped by ECclusters rather than the default. Two things to know rather than fix: the input is gitignored so the step cannot re-run from a clean clone, and the Mitochondrial cluster (dying cells, not a cell type) is still in the output. Clean
step3 3 Map to Ensembl IDs across three species. The 92 names broken in step 1 return nothing from BioMart and drop out of every downstream calculation with no error raised. The step is doing what it was asked; it inherits the damage. 92 genes lost
step4b 4 Cross-reference against human EC datasets. Yang S6 was read without naming a sheet, so only the first sheet loaded — the column means "is an arterial marker" (36 hits) and the capillary sheet, the most BBB-relevant one, was never opened. Wälchli's test was "expression above zero in any cell type", which 88.5% of all genes pass; that alone is why 1,131 of 1,526 genes score exactly 1. Winkler's parse is correct. Two reading bugs
step3b 5 Add orthology confidence. The script header says it recovers the genes step 1 dropped. It does not — it re-queries the same out-of-date names and recovers none of the 92. It is also where 196 one-to-many pairs enter the BBB set at only 25.8% protein identity, which step 5d then excludes from the control set but not from the BBB set. Overstated fix
step3c 6 Gene biotype audit. The check cannot fail. A CDS FASTA contains only protein-coding genes by definition, so a non-coding gene has no entry, comes back blank, and blank was not counted as a failure. 250 rows have no macaque label at all and were invisible to it. The reassuring answer was guaranteed by the method. Circular check
step4c 7 Build the liver control gene set. The third filter looked for a tissue called "brain"; the Human Protein Atlas has no such label, only regions (cerebral cortex, hippocampal formation, cerebellum…). Zero rows matched, the missing values became zeros, everything passed. The tell is in the saved file: every Brain_nTPM value is exactly 0.0. Recomputed properly, 86.6% of the "liver control" is brain-expressed, median brain 31.3 against median liver 31.2. It is a housekeeping set — among the most conserved genes in the genome. Filter never ran
step5a 8 Download CDS FASTAs. Ensembl release 113 for all three species — GRCh38, GRCm39, Mmul_10. Straight downloads, nothing to get wrong. Clean
step5b 9 Extract one CDS per gene. Takes the longest isoform. Longest is not necessarily equivalent: human and mouse can land on non-corresponding versions of the same gene, which makes them look more different than they are. This is the origin of the 224 impossible macaque scores visible in step 5c. Rough heuristic
step5b_alt — MANE Select / Ensembl Canonical transcripts. The standard alternative to the longest-isoform heuristic. It was written, it runs, and the canonical FASTAs already sit in genomes/. It was never switched in. Written, unused
step5c 10 Align and score the BBB genes. dN/dS was computed on sequences that were trimmed but never aligned — genuinely wrong, and correctly fixed later in step 5f. But the % identity was never recomputed, so every identity figure in the results still comes from here. Two numbers show the damage: 38% of genes came out with dS pinned at the 10.0 ceiling (2% after the 5f fix), and 224 one-to-one macaque pairs score under 85% — SLC2A1 at 71.4%, which is biologically impossible. Partly superseded
step5d 11 Score the liver control. Described as "the same measurements", but it kept only the single best-matching orthologue per gene while the BBB set kept every match including the bad ones. Different rules on the two sides of the comparison — and that alone reverses the headline direction. Asymmetric rules
step5e 12 First-pass statistics. Wilcoxon rank-sum (correct — these data are not normal) with rank-biserial effect sizes. Superseded by 5g, but not wrong. Clean
step5f 13 Recompute dN/dS, codon-aware. Translate to protein, align the proteins, map back onto codons, discard gapped codons, then score. This is the fix, and it mattered: one-to-many mouse dN/dS moved from 0.14 to 0.354. The only gap is scope — it fixed dN/dS and left % identity untouched. This is the fix
step5g 14 Multiple testing correction. Bonferroni and FDR across the four primary comparisons, with subgroup analyses honestly labelled exploratory. Correct. What is wrong is what went into it — steps 1, 4c and 5d. Clean
step5h 15 Mouse vs macaque. Same codon-aware pipeline with no human reference. No defect of its own — but it inherits the step 1 gene list, so its numbers move when step 1 is fixed. Clean

Three fixes change the conclusions

  1. step1 — point it at Daneman S6, drop S3/S4/S5, retire the Daneman_Filter column. Replace toupper() with a real ortholog mapping so the 92 lost genes come back.
  2. step4c — one line, so the brain filter matches the Atlas’s real region names. Then a separate decision about what the control should actually be.
  3. step5d — one orthologue rule applied to both groups.

Then re-run step5c through step5h. Everything else is numbers moving, not conclusions changing.

What we still need to figure out

These are not defects. They need a decision, a dataset, or both — and this is the section that grows as the literature review continues.

What should the control actually be?

Fixing the step4c filter gives a genuine liver set, but liver may not be the right comparator at all. Brain non-BBB genes, or genes matched on protein domain, would each test a different claim.

Needs — Dr. Clelland

Can the macaque arm rest on mouse-defined biology?

Every gene earned its place from a mouse study. Real macaque DNA is used throughout steps 5a–5h, but no macaque study tells us which genes macaque brain vessels actually switch on. The rhesus brain single-cell atlas (Science Advances 2023, ~1M nuclei, 28 regions, on CellxGene) would close this — and widens project scope.

Needs — a dataset and sign-off

Should % identity be recomputed the way dN/dS was?

Step 5f fixed dN/dS with codon-aware alignment and left identity alone. Switching step5b to MANE Select and re-running identity would likely remove the 224 impossible macaque scores. The canonical FASTAs already exist.

Needs — a decision, then compute time

Why did we never use Wälchli's 12 EC subtypes?

The dataset resolves capillary from arterial from venous endothelium. Step 4b collapsed all of it to a single above-zero test. The most valuable thing about the dataset is the one thing the pipeline never asked it.

Needs — a new analysis

Where did Giger 2010 come from, and what replaces it?

Logged as the macaque dataset. Its 13 samples are all human (taxid 9606) — the macaque in that paper belongs to Khaitovich et al. under a separate accession that was never downloaded. It also compares neurons to endothelium rather than brain to peripheral endothelium, so it is not a BBB gene list for any species.

Needs — literature review

Should step 2 be reproducible from a clean clone?

The Seurat input is gitignored and exists on one machine. The Mitochondrial cluster is also still sitting in the output matrix.

Needs — a housekeeping decision
