Data & Code

Processed datasets, scripts, and how to reproduce the analysis

Author

Yara Ismail

Published

September 17, 2026

Everything in this project lives in one repository: Mmynemious/BBB-Gene-Conservation.

Repository layout

BBB-Gene-Conservation/
├── raw_data/     original unmodified datasets from each paper
├── processed/    cleaned outputs — one CSV per pipeline step
├── genomes/      CDS FASTAs (gitignored — regenerated by step5a)
├── scripts/      one R script per numbered step, plus eval_* checks
├── site/         source for this website (.qmd + styles.css)
└── docs/         rendered site + the source papers as PDFs

Scripts — one per numbered step

Each script writes into processed/ and is named for its step. The audit gives a verdict for every one of them.

Script Writes Verdict
step1_extract_BBB_genelist.R master_BBB_genelist.csv Breaks results
step2_process_walchli_seurat.R Walchli2024_AverageExpression.csv Clean
step3_map_ensembl_crossspecies.R BBB_genes_crossspecies_ensembl.csv 92 genes lost
step4b_human_validation.R master_BBB_genelist_validated.csv Two reading bugs
step3b_biomart_orthology_confidence.R master_BBB_genelist_complete.csv Overstated fix
step3c_biotype_check.R gene_biotype_check.csv Circular check
step4c_liver_control_geneset.R liver_control_genelist.csv Breaks results
step5a_download_cds_fastas.R genomes/*.cds.all.fa.gz Clean
step5b_extract_cds_sequences.R genomes/cds_BBB_*.fa Rough heuristic
step5b_alt_canonical_transcripts.R genomes/cds_canonical_*.fa Written, unused
step5c_align_and_score.R conservation_scores_BBB.csv Partly superseded
step5d_liver_scoring.R conservation_scores_liver.csv Breaks results
step5e_statistics.R conservation_summary.txt Clean
step5f_recompute_dnds.R conservation_scores_combined_v2.csv Clean — this is the fix
step5g_stats_v2.R conservation_summary_v2.txt Clean
step5h_mouse_vs_macaque.R conservation_scores_mouse_macaque.csv Clean

Note the run order. step4b writes the file step3b reads, so the scripts execute 1 → 2 → 3 → 4b → 3b → 3c → 4c → 5a…, not in the order their names imply.

Reproducing the analysis

WarningOne step cannot be reproduced from a clean clone

step2 reads a Seurat object (Walchli2024_…SeuratObject.rds.gz) that is gitignored for size and exists only on the author’s machine. Its output, processed/Walchli2024_AverageExpression.csv, is committed, so every later step runs — but step 2 itself cannot be re-executed without obtaining the source object from the Wälchli supplementary data.

Requirements

# CRAN
install.packages(c("readr", "dplyr", "ggplot2", "knitr", "seqinr", "readxl"))

# Bioconductor
if (!require("BiocManager")) install.packages("BiocManager")
BiocManager::install(c("biomaRt", "Biostrings", "pwalign"))

# Seurat — required for step 2 only
install.packages("Seurat")

Ensembl release 113 is queried live through biomaRt, so results can shift as Ensembl updates. The CDS FASTAs are downloaded by step5a rather than committed — genomes/ is gitignored.

Running it

# from the repository root, in order
Rscript scripts/step1_extract_BBB_genelist.R
Rscript scripts/step2_process_walchli_seurat.R      # needs the Seurat object
Rscript scripts/step3_map_ensembl_crossspecies.R
Rscript scripts/step4b_human_validation.R           # note: before 3b
Rscript scripts/step3b_biomart_orthology_confidence.R
Rscript scripts/step3c_biotype_check.R
Rscript scripts/step4c_liver_control_geneset.R
Rscript scripts/step5a_download_cds_fastas.R        # large downloads
Rscript scripts/step5b_extract_cds_sequences.R
Rscript scripts/step5c_align_and_score.R            # slow — hours
Rscript scripts/step5d_liver_scoring.R              # slow — hours
Rscript scripts/step5e_statistics.R
Rscript scripts/step5f_recompute_dnds.R
Rscript scripts/step5g_stats_v2.R
Rscript scripts/step5h_mouse_vs_macaque.R
