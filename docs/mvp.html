Conservation MVP

Rough ideation of the new modular pipeline: orthologues and protein conservation for a small gene set, across human, macaque and mouse.

Author

Yara Ismail

Published

October 11, 2026

Rough ideation. This is the first, minimal version of the tool described under What’s currently being built. It covers the orthologue layer and protein identity only. The RNA layer is not built yet. The interpretation thresholds below are provisional and can be changed before each run.

What each column means

Column Meaning
Interpretation Highly conserved core barrier protein, moderately conserved, weakly conserved, or not suitable for simple cross-species comparison. Not suitable means the gene is not one-to-one in all three pairs, or the proteins differ in length beyond the tolerance
1:1 Whether Ensembl calls the gene one-to-one in all three pairs: human vs macaque, human vs mouse, macaque vs mouse
Identity % Ensembl’s percent identity: the share of one protein’s amino acids that are identical in the other, in Ensembl’s alignment. It depends on which protein you count from, so the download gives both directions for every pair. The table shows the value counted from the first species named
Lowest identity The lowest of all six identity values. The interpretation is based on this, so one weak pair is enough to lower it
aa Protein length in amino acids, for the protein Ensembl used in the comparison
Alignment Aligned, aligned with a length mismatch, or incomplete if a pair is missing
Pfam domains Protein domains found in the human protein

How to check a result by hand

  1. Open the gene in Ensembl. The gene name in the table links to its Ensembl page. Each row in the download carries the Ensembl page for all three species.
  2. Check the orthologues. On the human gene’s Ensembl page, open Comparative Genomics, Orthologues. The macaque and mouse genes, the type (1-to-1) and the identity numbers there should match the download.
  3. Check the release. The download records the Ensembl release and the date of the run. Numbers can change between releases.
  4. Check the identity yourself. The JSON download contains the aligned protein sequences for every pair and the exact API queries used, so any identity can be recounted from the alignment.

Limits of this version

  • One protein per gene. Ensembl compares one representative protein per gene. If that protein differs between species, for example a longer macaque model, identity drops and the length flag catches it. This is the same canonical transcript problem found in the audit.
  • Protein identity only. No dN/dS yet. That is the next sequence conservation module.
  • Thresholds are provisional. The 90%, 70% and 10% defaults are starting points, not values taken from a paper.
  • No RNA layer yet.

async function getJSON(path, tries){
  // Ensembl's homology service is slow and sometimes returns 500/503 or drops the
  // connection. Retry those with increasing waits; a 400 means the gene is unknown.
  tries = tries || 0;
  const url = API + path + (path.includes("?") ? ";" : "?") + "content-type=application/json";
  let r;
  try { r = await fetch(url); }
  catch(e){ r = null; }
  if (r && r.ok) return { data: await r.json(), url };
  const status = r ? r.status : 0;
  if ((status === 0 || status === 429 || status >= 500) && tries < 6){
    const after = r && parseFloat(r.headers.get("Retry-After"));
    const wait = after ? after * 1000 : Math.min(2000 * Math.pow(2, tries), 30000);
    await new Promise(res => setTimeout(res, wait));
    return getJSON(path, tries + 1);
  }
  const e = new Error(status ? "HTTP " + status : "network error"); e.status = status; e.url = url; throw e;
}

const ungapped = s => s ? s.replace(/-/g, "").length : null;
const r1 = x => x == null ? null : Math.round(x * 10) / 10;
const geneLink = (sp, id) => id ? "https://www.ensembl.org/" + PAGE[sp] + "/Gene/Summary?g=" + id : "";

function pairFrom(h){
  // One Ensembl Compara homology record -> identity read from each side.
  return {
    type: h.type,
    source_protein: h.source.protein_id, target_protein: h.target.protein_id,
    identity_source: h.source.perc_id, identity_target: h.target.perc_id,
    len_source: ungapped(h.source.align_seq), len_target: ungapped(h.target.align_seq),
    align_source: h.source.align_seq || null, align_target: h.target.align_seq || null
  };
}

async function runGene(symbol, s){
  const row = { gene: symbol, status: "ok", notes: [], queries: [] };
  try {
    const q1 = await getJSON("/homology/symbol/" + SP.human + "/" + encodeURIComponent(symbol) +
      "?target_species=" + SP.macaque + ";target_species=" + SP.mouse + ";type=orthologues;sequence=protein");
    row.queries.push(q1.url);
    const block = q1.data.data && q1.data.data[0];
    const homs = block ? block.homologies : [];
    row.human_gene_id = block ? block.id : null;
    const mac = homs.filter(h => h.target.species === SP.macaque);
    const mou = homs.filter(h => h.target.species === SP.mouse);
    row.n_macaque_orthologues = mac.length;
    row.n_mouse_orthologues = mou.length;

    if (mac.length){ const p = pairFrom(mac[0]); row.macaque_gene_id = mac[0].target.id; row.hm = p; }
    if (mou.length){ const p = pairFrom(mou[0]); row.mouse_gene_id = mou[0].target.id; row.hmo = p; }
    row.human_protein_id = (row.hm || row.hmo || {}).source_protein || null;
    row.macaque_protein_id = row.hm ? row.hm.target_protein : null;
    row.mouse_protein_id = row.hmo ? row.hmo.target_protein : null;

    if (mac.length === 1 && mou.length === 1){
      const q2 = await getJSON("/homology/id/" + SP.macaque + "/" + row.macaque_gene_id +
        "?target_species=" + SP.mouse + ";type=orthologues;sequence=protein");
      row.queries.push(q2.url);
      const b2 = q2.data.data && q2.data.data[0];
      const hit = b2 ? b2.homologies.find(h => h.target.id === row.mouse_gene_id) : null;
      if (hit) row.mm = pairFrom(hit);
      else row.notes.push("macaque and mouse orthologues are not paired with each other in Ensembl");
    }

    if (row.human_protein_id){
      try {
        const q3 = await getJSON("/overlap/translation/" + row.human_protein_id + "?type=Pfam;feature=protein_feature");
        row.queries.push(q3.url);
        const seen = {};
        row.domains = q3.data.filter(d => !seen[d.id] && (seen[d.id] = 1))
          .map(d => d.id + " " + (d.description || "")).join("; ");
      } catch(e){ row.domains = ""; row.notes.push("domain lookup failed"); }
    }
  } catch(e){
    row.status = e.status === 400 || e.status === 404 ? "symbol not found in Ensembl" : "request failed (" + e.message + ")";
  }
  return classify(row, s);
}

function classify(row, s){
  const pairs = [["hm","human vs macaque"],["hmo","human vs mouse"],["mm","macaque vs mouse"]];
  row.one_to_one = !!(row.hm && row.hmo && row.mm &&
    row.hm.type === "ortholog_one2one" && row.hmo.type === "ortholog_one2one" && row.mm.type === "ortholog_one2one");
  row.human_length = (row.hm || row.hmo || {}).len_source || null;
  row.macaque_length = row.hm ? row.hm.len_target : null;
  row.mouse_length = row.hmo ? row.hmo.len_target : null;

  // Alignment status: every pair aligned, and no pair differing in length beyond the tolerance.
  let lengthFlag = false;
  for (const [k, label] of pairs){
    const p = row[k]; if (!p) continue;
    p.identity_min = Math.min(p.identity_source, p.identity_target);
    if (p.len_source && p.len_target){
      const diff = Math.abs(p.len_source - p.len_target) / Math.max(p.len_source, p.len_target) * 100;
      p.length_diff_pct = r1(diff);
      if (diff > s.len){ lengthFlag = true; row.notes.push(label + " lengths differ by " + r1(diff) + "%"); }
    }
  }
  const allAligned = pairs.every(([k]) => row[k] && row[k].align_source);
  row.alignment_status = row.status !== "ok" ? "not run" :
    !allAligned ? "incomplete" : lengthFlag ? "aligned, length mismatch" : "aligned";

  const mins = pairs.map(([k]) => row[k] ? row[k].identity_min : null).filter(x => x != null);
  row.lowest_identity = mins.length === 3 ? r1(Math.min(...mins)) : null;

  if (row.status !== "ok"){ row.interpretation = "not run"; row.notes.unshift(row.status); }
  else if (!row.one_to_one){
    row.interpretation = "not suitable for simple cross-species comparison";
    row.notes.unshift("not one-to-one in all three pairs (macaque: " + row.n_macaque_orthologues + ", mouse: " + row.n_mouse_orthologues + " orthologues)");
  }
  else if (lengthFlag) row.interpretation = "not suitable for simple cross-species comparison";
  else if (row.lowest_identity >= s.high) row.interpretation = "highly conserved core barrier protein";
  else if (row.lowest_identity >= s.mod) row.interpretation = "moderately conserved";
  else row.interpretation = "weakly conserved";
  return row;
}

function flat(r){
  const g = (p, k) => p ? p[k] : null;
  return {
    gene: r.gene,
    status: r.status,
    interpretation: r.interpretation,
    one_to_one: r.one_to_one,
    lowest_identity: r.lowest_identity,
    human_vs_macaque_identity_from_human: g(r.hm,"identity_source"),

    human_vs_mouse_identity_from_human: g(r.hmo,"identity_source"),
    human_vs_mouse_identity_from_mouse: g(r.hmo,"identity_target"),
    macaque_vs_mouse_identity_from_macaque: g(r.mm,"identity_source"),
    macaque_vs_mouse_identity_from_mouse: g(r.mm,"identity_target"),
    human_length_aa: r.human_length,
    macaque_length_aa: r.macaque_length,
    mouse_length_aa: r.mouse_length,
    alignment_status: r.alignment_status,

    human_protein_id: r.human_protein_id || null,

async function runGenes(genes){
  ["mvp-run","mvp-csv","mvp-json","mvp-retry"].forEach(id => $(id).disabled = true);
  const prog = $("mvp-progress"); prog.hidden = false; prog.max = genes.length; prog.value = 0;
  const t0 = Date.now();
  let next = 0;
  const worker = async () => {
    while (next < genes.length){
      const i = next++;
      const row = await runGene(genes[i], settings);
      const at = results.findIndex(r => r.gene === row.gene);
      if (at >= 0) results[at] = row; else results.push(row);
      prog.value++;
      const left = Math.round((Date.now() - t0) / prog.value * (genes.length - prog.value) / 1000);
      $("mvp-status").textContent = prog.value + " of " + genes.length + " genes done" +
        (prog.value < genes.length ? ", about " + Math.max(1, Math.round(left / 60)) + " min left" : "");
    }
  };
  await Promise.all([worker(), worker(), worker()]);
  const order = $("mvp-genes").value.split(/[\s,;]+/).map(g => g.trim().toUpperCase());
  results.sort((a, b) => order.indexOf(a.gene) - order.indexOf(b.gene));
  render();
  const failed = results.filter(r => r.status.startsWith("request failed")).length;
  $("mvp-status").textContent = "Done" + (failed ? ". " + failed + " genes failed because Ensembl did not respond; retry them below." : ".");
  prog.hidden = true;
  $("mvp-retry").hidden = !failed;
  ["mvp-run","mvp-csv","mvp-json","mvp-retry"].forEach(id => $(id).disabled = false);
}

  results = []; $("mvp-table").innerHTML = ""; $("mvp-summary").innerHTML = "";

  try {
    const info = await getJSON("/info/data");
    meta = { ensembl_release: info.data.releases[0], run_date: new Date().toISOString().slice(0,10),

## What each column means

| Column | Meaning |
|---|---|
| **Interpretation** | Highly conserved core barrier protein, moderately conserved, weakly conserved, or not suitable for simple cross-species comparison. Not suitable means the gene is not one-to-one in all three pairs, or the proteins differ in length beyond the tolerance |
| **1:1** | Whether Ensembl calls the gene one-to-one in all three pairs: human vs macaque, human vs mouse, macaque vs mouse |
| **Identity %** | Ensembl's percent identity: the share of one protein's amino acids that are identical in the other, in Ensembl's alignment. It depends on which protein you count from, so the download gives both directions for every pair. The table shows the value counted from the first species named |
| **Lowest identity** | The lowest of all six identity values. The interpretation is based on this, so one weak pair is enough to lower it |
| **aa** | Protein length in amino acids, for the protein Ensembl used in the comparison |
| **Alignment** | Aligned, aligned with a length mismatch, or incomplete if a pair is missing |
| **Pfam domains** | Protein domains found in the human protein |

## How to check a result by hand

1. **Open the gene in Ensembl.** The gene name in the table links to its Ensembl page. Each
   row in the download carries the Ensembl page for all three species.
2. **Check the orthologues.** On the human gene's Ensembl page, open *Comparative Genomics,
   Orthologues*. The macaque and mouse genes, the type (1-to-1) and the identity numbers there
   should match the download.
3. **Check the release.** The download records the Ensembl release and the date of the run.
   Numbers can change between releases.
4. **Check the identity yourself.** The JSON download contains the aligned protein sequences
   for every pair and the exact API queries used, so any identity can be recounted from the
   alignment.

## Limits of this version

- **One protein per gene.** Ensembl compares one representative protein per gene. If that
  protein differs between species, for example a longer macaque model, identity drops and the
  length flag catches it. This is the same canonical transcript problem found in the
  [audit](audit.qmd).
- **Protein identity only.** No dN/dS yet. That is the next sequence conservation module.
